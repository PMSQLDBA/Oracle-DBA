## Oracle Database Administration — 10-Lesson Index

| Lesson | Topic                                                  | Key Areas Covered                                                                                                                                                                   |
| -----: | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  **1** | **Oracle Database Fundamentals & Architecture**        | Oracle DB concepts, instances, databases, memory structures, processes, storage structures, CDB/PDB architecture, DBA responsibilities                                              |
|  **2** | **Installation & Initial Configuration**               | Oracle Database installation on **Windows & Linux/Unix**, prerequisites, Oracle Home/Base, ORACLE_SID, DBCA, listener, services, networking, post-install configuration             |
|  **3** | **Database & User Administration**                     | Creating databases/PDBs, users, schemas, profiles, privileges, roles, authentication, password management, tablespaces, quotas, security basics                                     |
|  **4** | **Storage, Backup & Recovery Administration**          | Datafiles, control files, redo/undo, ARCHIVELOG, RMAN, backup strategies, restore/recovery, point-in-time recovery, Flashback, disaster recovery fundamentals                       |
|  **5** | **Oracle Networking & Connectivity**                   | Listener, `tnsnames.ora`, `sqlnet.ora`, Easy Connect, service registration, client connectivity, TNS troubleshooting, database links                                                |
|  **6** | **Performance Monitoring & Troubleshooting**           | AWR, ADDM, ASH, wait events, execution plans, SQL tuning, memory management, CPU/I/O issues, blocking/locking, common production problems                                           |
|  **7** | **Patching & Maintenance**                             | Oracle patches, Release Updates (RUs), one-off patches, OPatch, OPatchAuto, inventory, patch prerequisites, rollback, patching **Windows & Linux/Unix**, post-patch validation      |
|  **8** | **Migration & Upgrade Administration**                 | Database migrations, Data Pump, RMAN migration, transportable technologies, cross-platform migration, upgrade planning, AutoUpgrade, compatibility, rollback strategy               |
|  **9** | **High Availability, RAC & Data Guard**                | RAC fundamentals, Clusterware, ASM overview, Data Guard, physical standby, redo transport, apply, switchover/failover, Broker, HA architecture                                      |
| **10** | **Production DBA, Automation & End-to-End Operations** | Monitoring, jobs, alerts, capacity planning, security hardening, automation, incident management, backup validation, upgrades/patching runbooks, DR drills, real-time DBA scenarios |

### Official Oracle documentation basis

The lessons should be aligned primarily with Oracle's official documentation for the **specific Oracle Database release being studied**, because installation, patching, upgrade, and migration procedures vary by release and operating system.
